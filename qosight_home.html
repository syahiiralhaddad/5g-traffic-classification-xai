1

Upload Your Network Data

QoSight accepts a CSV file containing your 5G network measurements. Each row represents a captured packet or time-window sample with the following QoS parameters: packet loss, throughput, latency, jitter, and packet length. Optionally include a traffic_type column for ground-truth comparison.

CSV format date + time columns 5 QoS features optional ground truth
2

Preprocessing & Feature Engineering

The backend (Python/Flask) loads your CSV and applies StandardScaler normalization to ensure all QoS features contribute equally regardless of their original scale. Datetime columns are parsed for time series analysis. The data is split into train/test sets using an 80/20 time-based split to prevent temporal data leakage.

StandardScaler 80/20 time-based split No data leakage
3

Stacking Ensemble Classification

Three base learners are trained simultaneously on the training set: K-Nearest Neighbors (KNN) captures local neighborhood patterns, Support Vector Machine (SVM) finds optimal decision boundaries in high-dimensional space, and Random Forest (RF) uses bagged decision trees for robust feature importance. Their out-of-fold predictions are stacked as meta-features for a Logistic Regression meta-learner, which learns the optimal combination — consistently achieving 99%+ accuracy on 5G traffic.

KNN (k=5) SVM (RBF kernel) Random Forest (100 trees) Logistic Regression meta 5-fold cross-validation
4

Time Series Analysis

Beyond classification, QoSight analyzes temporal traffic patterns — hourly distributions, daily trends, and day-of-week heatmaps. This reveals when different traffic types (Gaming, Social Media, Video, Voice) peak throughout the day and over time, enabling proactive network capacity planning.

Hourly patterns Daily trend Heatmap (hour × day) QoS per-class means
5

Explainable AI (XAI)

Finally, an LLM (via HuggingFace Inference API) generates a natural-language explanation for each traffic class, describing the distinctive QoS characteristics the model learned to associate with it. This makes every model decision transparent and actionable for network engineers, even without a data science background.

LLM-powered Per-class explanations Feature importance context Human-readable
